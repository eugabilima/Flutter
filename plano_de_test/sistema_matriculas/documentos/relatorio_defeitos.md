## Observações

Os defeitos deverão ser registrados somente após a execução, repetição e confirmação dos casos de teste.

Para cada possível defeito serão realizados os seguintes procedimentos:

1. Executar o caso de teste;
2. Identificar o comportamento inesperado;
3. Repetir a execução;
4. Confirmar o problema;
5. Registrar uma evidência;
6. Criar o registro do defeito;
7. Classificar a severidade;
8. Classificar a prioridade;
9. Somente depois realizar a correção.

Nenhum defeito será considerado confirmado sem evidência.
